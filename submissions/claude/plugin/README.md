# Epic Stocks (Unofficial)

Understand Epic employee grants, vesting and stock loans, reconcile records and
explore compensation and retirement scenarios. This is an independent project,
not made, endorsed or supported by Epic Systems Corporation. It does not execute
trades or move money. Projections are uncertain, assumption-dependent estimates.

Install the plugin, connect its Epic Stocks connector, sign in and approve only
the permissions you need. Ask “Help me get started with Epic Stocks.” The bundled
get-started skill guides setup, website import, preview/confirmation,
reconciliation and planning. Ordinary users need their own Epic Stocks account
and records. Directory reviewers receive independent fictional accounts.

Examples:

- Show my equity and explain my outstanding stock loans.
- Reconcile the grant and loan figures I provide; preview any changes first.
- Compare retirement dates using my saved spending assumptions.

If interactive UI is unavailable, request the structured/text result. If the
connection expires, reconnect through OAuth. No static API key is required.
[Setup and troubleshooting](https://epic-stocks.com/mcp-setup).

## Privacy Policy

[Public privacy policy](https://epic-stocks.com/privacy) describes collected
profile/financial fields, storage, assistant sharing, retention, export,
disconnect and deletion. The connector accesses only selected account scopes;
no assistant memory/history/files are retrieved. Use the website parser for raw
imports and explicitly confirm financial edits. Do not submit government IDs,
passwords or payment credentials in chat or tools. Only fictional data appears
in this package. Support: the website's private Report a problem flow; public
non-confidential bugs may use the repository's GitHub issues. The publisher must
also supply its monitored contact in the directory form.
